# Upstream and derivative boundary

Matrix World is derived from the StarNet codebase.

- Upstream repository: https://github.com/LimitedByHumanity/Star-Net
- Fork: https://github.com/mulasty/Matrix-World
- Matrix development branch: `matrix-rebuild`
- Upstream default branch observed at fork time: `feat/harness-backend`

## License handling

The upstream repository states that its **code** is MIT licensed, while the StarNet name, logo, station artwork, sprites, and other brand identity are not included in that MIT grant.

Matrix World therefore:
- retains required MIT attribution for upstream code,
- uses a distinct Matrix World name and identity,
- must replace upstream protected artwork before distribution,
- keeps derivative-specific UI/branding changes isolated where possible for easier auditing.

This file is engineering documentation, not legal advice.
